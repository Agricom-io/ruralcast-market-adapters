# Samples
Real adapter output from 2026-09-04, truncated to the last 12 periods for repository size.
Regenerate the full series with:
```
python -m ruralcast_adapters.surs -o surs_monthly.csv
python -m ruralcast_adapters.dgagri --years 2019 2020 2021 2022 2023 2024 2025 2026 -o si_weekly.csv
```
Sources: SURS 0410811S (CC BY 4.0) · DG AGRI agrifood API (EU open data).
